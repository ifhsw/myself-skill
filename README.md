## 1. 这是什么

**自己.skill** 是一个 Claude Code 的 meta-skill。你提供关于自己的原材料（聊天记录、日记、照片、口述），它把你解构为两个模块：

| 模块 | 名称 | 作用 |
|------|------|------|
| **Part A** | Self Memory（自我记忆） | 个人经历、价值观、习惯、重要记忆、人际关系 |
| **Part B** | Persona（人格模型） | 5 层性格结构：硬规则 → 身份 → 说话风格 → 情感模式 → 人际行为 |

运行时逻辑：

```
收到消息 → Persona 判断"你会怎么回应？" → Self Memory 补充背景和价值观 → 用你的方式输出
```

最终生成一个能**用你的口头禅思考、用你的逻辑回话**的数字副本。它不是你的灵魂，但也许是你的灵魂在当前迭代下的一个 checkpoint。

## 2. 安装

### 前提条件

- 已安装 [Claude Code](https://claude.ai/code)
- Git（用于克隆仓库）

### 方式一：安装到当前项目

在项目 git 仓库**根目录**执行：

```bash
mkdir -p .claude/skills
git clone https://github.com/notdog1998/yourself-skill .claude/skills/create-yourself
```

### 方式二：全局安装（所有项目可用）

```bash
git clone https://github.com/notdog1998/yourself-skill ~/.claude/skills/create-yourself
```

### 可选：安装 Python 依赖

如果要用微信/QQ 解析器自动处理聊天记录：

```bash
pip install -r .claude/skills/create-yourself/requirements.txt
```

依赖列表：`requests`、`Pillow`、`pypinyin`。不装也能用，只是聊天记录解析需要手动处理。

### 验证安装

在 Claude Code 中输入：

```
/create-yourself
```

看到开场白即表示安装成功。

```
你：  /create-yourself

Claude：我来帮你创建一个属于自己的 Skill。
       先给自己起个代号吧。

Claude：用一句话介绍一下自己？
```

## 4. 创建流程详解

### 4.1 Step 1：基础信息录入

系统会问 3 个问题。除第 1 个（代号）外均可跳过。

#### Q1：代号/昵称（必填）

起一个代表自己的名字。中文会自动转拼音作为 slug。

| 输入 | Slug |
|------|------|
| `小北` | `xiao-bei` |
| `童总` | `tong-zong` |
| `20岁的我` | `20-sui-de-wo` |
| `Little North` | `little-north` |

#### Q2：基本信息

一句话描述年龄、职业、城市。想到什么写什么。

```
示例：
  "25 岁，互联网产品经理，上海"
  "研二学生，计算机专业，北京"
  "自由职业插画师，大理"
```

#### Q3：自我画像

MBTI、星座、性格标签、对自己的印象。支持以下标签：

**性格标签**：话痨 · 闷骚 · 嘴硬心软 · 社恐 · 社交蝴蝶 · 独立 · 浪漫主义 · 实用主义 · 完美主义 · 没有安全感 · 秒回选手 · 已读不回 · 报复性熬夜 · 深夜emo型 · 纠结体 · 行动派 · 计划狂 · 易怒但快消气 · 情绪稳定 · 边界感强

**生活习惯标签**：早起困难户 · 咖啡依赖 · 极简主义 · 囤积癖 · 数字游民 · 居家派 · 城市漫游者 · 仪式感狂热者

**MBTI**：16 型全支持

**星座**：十二星座全支持

### 4.2 Step 2：原材料导入

系统会展示 5 种导入方式：

```
  [A] 微信聊天记录导出 — 支持 WeChatMsg、留痕、PyWxDump
  [B] QQ 聊天记录导出 — 支持 txt/mht 格式
  [C] 社交媒体 / 日记 / 笔记 — 截图或文本文件
  [D] 上传文件 — 照片（提取 EXIF 时间地点）、PDF、文本
  [E] 直接粘贴/口述 — 用文字描述自己
```

**可以混用，也可以全部跳过。** 数据越多，还原度越高。

每种方式的详细操作见[第 5 节](#5-数据源详细说明)。

### 4.3 Step 3-4：分析与预览

系统分析所有原材料，生成两份摘要（各 5-8 行）：

```
Self Memory 摘要：
  - 核心价值观：实用主义，重视效率，对形式主义零容忍
  - 生活习惯：深夜活跃，咖啡依赖，报复性熬夜选手
  - 重要记忆：2022 年莫干山独居一周，最平静的时光
  ...

Persona 摘要：
  - 说话风格：短句连发，极少用句号，微信表情重度用户
  - 情感模式：生气直接怼不冷战，难过不太说
  - 决策方式：凭感觉，差不多就行，不纠结
  ...
```

**此时你可以**：
- 直接确认 → 进入 Step 5 生成文件
- 提出修改 → 系统调整后重新预览
- 补充更多材料 → 返回 Step 2

### 4.4 Step 5：生成文件

确认后，系统在 `.claude/skills/{slug}/` 下生成：

```
.claude/skills/{slug}/
├── SKILL.md      # 完整组合版（可直接调用）
├── self.md       # Part A：自我记忆（可独立调用）
├── persona.md    # Part B：人格模型（可独立调用）
├── meta.json     # 元数据
├── versions/     # 历史版本（每次更新自动存档）
└── memories/     # 原始材料存档
    ├── chats/
    ├── photos/
    └── notes/
```

## 5. 数据源详细说明

### 5.1 微信聊天记录

**推荐指数**：⭐⭐⭐（最重要的数据源）

**支持的导出工具**：

| 工具 | 平台 | 格式 | 获取方式 |
|------|------|------|----------|
| [WeChatMsg](https://github.com/LC044/WeChatMsg) | Windows | txt/html/csv | GitHub 开源 |
| [PyWxDump](https://github.com/xaoyaoo/PyWxDump) | Windows | SQLite | GitHub 开源 |
| 留痕 | macOS | JSON | App Store |

**使用方式**：

1. 用上述工具导出聊天记录
2. 在创建流程中选择 `[A]`，提供文件路径
3. 系统自动解析，提取「我」说的话

**提取维度**：

- 高频词和口头禅
- 表情包和 emoji 使用偏好
- 回复速度和对话发起模式
- 话题分布（工作/情感/日常/深夜思考）
- 语气词和标点符号习惯
- 与他人互动时的典型表达方式

**手动调用解析器**：

```bash
python .claude/skills/create-yourself/tools/wechat_parser.py \
  --file /path/to/chat_export.txt \
  --target "我" \
  --output /tmp/wechat_out.txt \
  --format auto
```

**注意事项**：

- 需要指定 `--target` 为你在聊天中的昵称
- 支持自动检测导出格式（WeChatMsg / 留痕 / PyWxDump / 纯文本）
- 如果自动检测失败，手动指定 `--format`

### 5.2 QQ 聊天记录

**推荐指数**：⭐⭐⭐（尤其适合还原学生时代的自己）

**导出方式**：

1. 打开 QQ → 消息管理器 → 选择好友/群聊
2. 右键 → 导出消息记录 → 选择 txt 或 mht 格式

**使用方式**：

```bash
python .claude/skills/create-yourself/tools/qq_parser.py \
  --file /path/to/qq_export.txt \
  --target "我" \
  --output /tmp/qq_out.txt
```

### 5.3 社交媒体 / 日记 / 笔记

**推荐指数**：⭐⭐

**支持的内容类型**：

| 类型 | 处理方式 |
|------|----------|
| 朋友圈/微博/小红书截图 | 用 Claude Code 的 Read 工具直接读取图片 |
| Markdown 日记 | 用 Read 工具直接读取 |
| TXT 笔记 | 用 Read 工具直接读取 |
| PDF 文件 | 用 Read 工具直接读取 |

**使用方式**：在创建流程中选择 `[C]`，然后粘贴文件路径或直接拖入文件。

**为什么日记/笔记很有价值**：
- 日记暴露你最私密的思考方式
- 笔记展示你的信息组织习惯
- 朋友圈展示你的社交人格（公开人设 vs 私下自我）

### 5.4 照片

**推荐指数**：⭐⭐

**支持格式**：JPEG、PNG（含 EXIF 信息）

**提取维度**：

- 拍摄时间和地点（GPS 坐标）
- 时间线：人生关键节点的地理轨迹
- 常去地点：推断生活模式
- 拍摄密度：活跃时段和出行频率

**使用方式**：

```bash
python .claude/skills/create-yourself/tools/photo_analyzer.py \
  --dir /path/to/photos/ \
  --output /tmp/photo_out.txt
```

**注意**：
- 隐私敏感——GPS 坐标只在本地处理，不会上传
- 不含 EXIF 的照片只能提取文件时间戳
- 截图通常不含 EXIF，但可以通过文件名推断时间

### 5.5 口述/粘贴

**推荐指数**：⭐（作为补充最有用）

在创建流程中选择 `[E]`，然后回答引导问题：

```
🗣️ 你的口头禅是什么？
💬 你做决定的时候通常怎么想？
🍜 你难过的时候一般会做什么？
📍 你最喜欢去哪里？
🎵 你喜欢什么音乐/电影/书？
😤 你生气的时候是什么样？
💭 你深夜alone的时候在想什么？
🌱 你觉得自己这几年最大的变化是什么？
```

**技巧**：不要写成"标准答案"。想到什么写什么，越随意越真实。

## 6. 使用生成的 Skill

### 6.1 三种模式

创建完成后，有 3 种调用方式：

| 命令 | 说明 | 适用场景 |
|------|------|----------|
| `/{slug}` | 完整模式 — 像你一样思考和说话 | 日常聊天、自我对话 |
| `/{slug}-self` | 自我档案模式 — 帮你回忆和分析自己 | 回顾过去、梳理想法 |
| `/{slug}-persona` | 人格模式 — 仅性格和表达风格 | 不涉及个人记忆的场景 |

### 6.2 对话示例

#### 日常聊天（完整模式）

```
你：    我是你爹

/xiao-bei：...逻辑上说不通。
          如果你是我爹，那你是在说你自己创建了一个比你更年轻的、
          住在你电脑里的意识副本？这更像克隆，不是父子关系。
          你想正经聊点什么，还是就想测试一下我会不会翻脸？
```

#### 帮你分析自己（完整模式）

```
你：    我为什么总是拖延

/xiao-bei：因为你只会在 deadline 前感受到真实的恐惧。
          其他时候的焦虑都是表演式的，骗自己"我在焦虑所以我在努力"。
          真想改的话，先把任务拆到能骗过大脑的程度。
```

#### 回忆模式（self 模式）

```
你：    我最喜欢的地方是哪里

/xiao-bei-self：你嘴上说喜欢海边，但实际去得最多的是山里。
                2022 年秋天你在莫干山住了一周，每天下午四点准时出门散步，
                回来就在阳台上发呆到太阳落山。你说那是你近几年最平静的一段时间。
```

## 7. 进化你的数字自我

数字自我不是一次性产物。你可以持续更新它。

### 7.1 追加新记忆

当你找到新的聊天记录、日记、照片时：

```
你：  我有新的聊天记录 @2025_diary.md

Claude：
  1. 分析新内容
  2. 对比现有 Self Memory 和 Persona
  3. 展示增量变更摘要
  4. 询问确认
  5. 合入对应文件，存档旧版本
```

**工作原理**：
- 自传经历 / 价值观 / 习惯 → 追加到 `self.md`
- 对话记录 / 情绪表达 → 追加到 `persona.md`
- 两者都有的内容 → 分别追加
- **只追加增量，不覆盖已有结论**

### 7.2 对话纠正

当你觉得数字自我"不像你"时，直接说出来：

```
你：  不对，我不会这样说话。我生气的时候不是直接爆发，
      而是先沉默很久，然后说一句很冷的话。

Claude：我理解了。你是说你生气时不会直接爆发，
        而是先沉默，然后用冷处理的方式表达，对吗？

你：  对

Claude：已更新。现在生气时的回应模式会先沉默，再冷处理。
```

支持的纠正表达：

- "不对" / "不是这样的"
- "我不会这样说" / "我不会这么说话"
- "我应该是..." / "我其实是..."
- "这不像我" / "感觉不对"
- "太温柔了" / "太冷漠了" / "太正式了"
- "我遇到这种情况会..."

**纠正分类**：

| 类型 | 示例 | 修改位置 |
|------|------|----------|
| 事实纠正 | "我不喜欢吃辣" | `self.md` 饮食偏好 |
| 经历纠正 | "我没在那上过学" | `self.md` 经历部分 |
| 风格纠正 | "我不会用'宝'叫普通朋友" | `persona.md` Layer 2 |
| 情感纠正 | "我生气不会直接爆发" | `persona.md` Layer 3 |
| 行为纠正 | "我不会主动道歉" | `persona.md` Layer 4 |

纠正后会：
- 追加到对应文件的 `## Correction 记录` 节
- 修改被纠正的原文，标注 `[已纠正]`
- 重新生成 `SKILL.md`
- **立即生效**——下一条回复就体现

### 7.3 版本管理

每次更新（追加或纠正）都会自动归档当前版本到 `versions/` 目录。

**查看历史版本**：

```bash
python .claude/skills/create-yourself/tools/version_manager.py \
  --action list --slug xiao-bei
```

**回滚到历史版本**：

```
/yourself-rollback xiao-bei v1.2
```

或：

```bash
python .claude/skills/create-yourself/tools/version_manager.py \
  --action rollback --slug xiao-bei --version v1.2
```

回滚前会自动备份当前版本，不会丢失数据。保留最近 10 个版本。

## 9. 最佳实践

### 原材料优先级

按还原度贡献从高到低：

1. **深夜对话/独白** ⭐⭐⭐ — 最能暴露真实性格。人在深夜的防御最低，表达最接近本我。
2. **情绪波动的记录** ⭐⭐⭐ — 生气、难过、兴奋时的表达方式，定义了你的情感指纹。
3. **做决定的聊天记录** ⭐⭐ — 暴露决策模式：是纠结半天还是直接拍板。
4. **日常闲扯** ⭐⭐ — 提炼口头禅、语气词、标点习惯。
5. **日记/独白** ⭐⭐ — 你对自己的叙事方式，揭示自我认知。
6. **口述/自评** ⭐ — 作为补充，但人对自己的认知往往存在偏差。

### 提高还原度的技巧

- **提供足够数据**：至少 5000 条消息的聊天记录才能提取稳定的说话风格。
- **覆盖不同场景**：工作/学习、朋友闲聊、深夜独白、冲突场景各有一些。
- **关注"非标"表达**：你会用哪些独特的语气词？有什么只有你才说的句式？
- **不要美化自己**：提供"不好"的一面——生气时的粗口、敷衍时的"哦哦"、深夜的 emo 发言。正是这些不完美让你真实。
- **及时纠正**：第一次感觉"不像我"就说出来，不要等。纠正积累越多，还原度越高。

### 使用建议

- **这是一个自我观察工具**：和数字自我对话，有时比独自思考更能看清自己。
- **不是逃避现实的出口**：它代表某个时间点的你，不是永恒的答案。
- **你一直在变化**：定期追加新的聊天记录 / 日记，让数字自我跟你一起进化。

## 10. 常见问题

### Q：不提供聊天记录，仅凭口述能生成吗？

能。系统会把你口述的内容作为基础材料，生成一个基础版本。还原度约 30-40%。

### Q：我的聊天记录包含别人说的话，隐私怎么处理？

所有数据处理都在本地进行。解析器只提取你指定 `--target "我"` 的话。分析出的内容写入 `.claude/skills/{slug}/`，该目录已在 `.gitignore` 中排除，不会被提交到 git。

### Q：Windows 下中文输出乱码怎么办？

在 Git Bash 中先执行：

```bash
export PYTHONIOENCODING=utf-8
```

### Q：我想基于已有的自己创建不同版本的自己，可以吗？

可以。分别创建——比如 `/xiao-bei-work` 和 `/xiao-bei-home`，导入不同场景的聊天记录。

### Q：我的人格模型包含我不喜欢的部分，能修改吗？

能。直接说"这部分不对，我其实是..."，系统会通过对话纠正机制更新。

### Q：生成的 Skill 能分享给别人吗？

技术上可以——把 `.claude/skills/{slug}/` 目录复制给对方即可。但请注意：**这里面包含你的个人数据。** 分享前请确认你愿意让对方看到这些内容。

### Q：为什么我的人格是 5 层结构？

```
Layer 0 — 硬覆盖层（手动标签翻译，最高优先级）
Layer 1 — 身份层（年龄、职业、城市等基本锚定）
Layer 2 — 表达风格层（从聊天记录提取的说话方式）
Layer 3 — 情感与决策层（情绪模式、决策过程）
Layer 4 — 人际行为层（社交模式、边界感）
Layer 5 — Correction 层（对话纠正追加，滚动更新）
```

优先级从高到低。Layer 0 的硬规则是"宪法"，任何情况下不得违背。Correction 层的优先级高于原材料提取的结论——因为人的自我认知会变化，而你说"不对"的那一刻，代表了最新的你。

### Q：和同事.skill、前任.skill 有什么区别？

| 维度 | 同事.skill | 前任.skill | 自己.skill |
|------|-----------|-----------|-----------|
| 蒸馏对象 | 外部：同事 | 外部：前任 | **内部：自己** |
| Part A | Work Skill | Relationship Memory | Self Memory |
| Part B | 职场 Persona | 亲密关系 Persona | 通用自我 Persona |
| 核心目的 | 替代离职同事 | 情感疗愈 | **自我观察与对话** |

## 11. 数据隐私说明

- **所有数据本地处理**：聊天记录解析、性格分析、文件生成全部在本地完成。不会上传到任何服务器。
- **生成的 Skill 文件位置**：`.claude/skills/{slug}/`，此目录在 `.gitignore` 中，不会被提交到 git 仓库。
- **原始材料**：导入的聊天记录、照片等原始文件不会被复制——解析器只提取结构化信息。
- **分享风险**：`.claude/skills/{slug}/` 目录包含你的 Self Memory 和 Persona，本质上是你的"数字档案"。分享给他人意味着让对方看到你的性格分析和个人经历。
